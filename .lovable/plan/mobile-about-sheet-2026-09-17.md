# Mobile About sheet

## Build
- Replace the passive About label on each Notepage with a tap target that opens a bottom sheet on mobile.
- Present the owner in the requested order: full name and portrait, full-length bio, writing country, interests, then external links.
- Add a single-color Uganda silhouette sized as a prominent notebook-style stamp, with the country name beneath it.
- Add a close control, tap-outside dismissal, Escape-key dismissal, scroll locking, and accessible sheet labels.
- Keep the sheet visually inherited from each Notepage’s custom colors and fonts.

## Content
- Extend each sample Notepage profile with a full name, complete bio, country, interests, links, and a portrait treatment.
- Use appropriate sample profile content for existing demo writers where details have not been supplied.

## Responsive behavior
- Mobile: sheet slides upward from the bottom and can scroll when content exceeds the viewport.
- Larger screens: show the same profile content in a restrained dialog so About remains usable everywhere.

## Verification
- Check the Derrick Notepage at mobile size, including open/close behavior, content order, silhouette scale, scrolling, and layout overflow.
- Confirm the preview builds without errors.
